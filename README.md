# Deepwater Productions

Phase 1 clickable demo for the Deepwater Productions portfolio site. See `/docs` (start with `docs/index.md` and `docs/guardrails.md`).

## Commands

```sh
npm install        # install dependencies
npm run dev        # dev server at http://localhost:3000
npm run build      # build + typecheck (prerenders all routes to dist/)
npm run deploy     # build + wrangler deploy (Cloudflare Workers Static Assets)
npm run cf-typegen # generate Cloudflare types
```
